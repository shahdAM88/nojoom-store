# ⭐ Nojoom Activity Rewards Store

An interactive web-based rewards system designed for student activities and competitions.

The platform allows students to enter their name and class, browse available rewards, and select their preferred reward.

## ✨ Features

- Simple and student-friendly interface
- Multiple reward options
- Reward confirmation before submission
- Celebration screen with animated confetti
- Supervisor login
- Supervisor dashboard
- Student selection tracking
- Search and class filtering
- Duplicate selection detection
- Start a new competition and reset current results
- Responsive design for desktop, tablet, and mobile

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Local Storage

## 🚧 Project Status

The project is currently under development.

The current version uses Local Storage to test the interface and core functionality before connecting the application to a database.

## 🔮 Planned Development

The project is planned to include database integration to support:

- Shared student selections across multiple devices
- One reward selection per student for each competition
- Centralized competition data for supervisors
- Starting a new competition while allowing students to participate again
- More reliable student identification and duplicate prevention
- Persistent and synchronized data across devices

The current Local Storage implementation will later be replaced with database-backed data management.

## 🎯 Purpose

This project was created to make student activity rewards more interactive, organized, and enjoyable while giving supervisors an easy way to manage competitions and track student reward selections.
